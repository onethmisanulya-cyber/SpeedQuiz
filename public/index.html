Real-time multiplayer quiz. No installs, no accounts.

How to play

Speed Quiz is a real-time, room-based multiplayer quiz game. Players join a shared room using a unique room code, enter a display name, and wait in the lobby until the host starts the game. The lobby shows the host, connected players, disconnected participants, and each player’s identifying colour. During the game, participants answer questions as quickly as possible, while the system tracks their performance and displays a live leaderboard. At the end, players can view the final results and replay the game in the same room.

  1. Join with the 4-letter room code and a display name.
  2. Wait in the lobby until the host starts.
  3. Answer each question as quickly as possible.
  4. Watch the live leaderboard, then the final results.
